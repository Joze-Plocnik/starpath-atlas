# starpath
A blank-sky navigation game: locate hidden stars within 2 degrees using a reference constellation.

Run locally with `python -m http.server 8000 --bind 127.0.0.1`, then open http://localhost:8000.

Play the new **Constellation game** at http://localhost:8000/constellations.html, or use the link in the original game's header. Each round shows only the stars of one constellation, with no star names, connecting lines, borders, or other constellations' stars until you discover them. Enter its full Latin name to earn one point and reveal its IAU border. Then type a bordering constellation's Latin name and click inside that constellation's actual region to earn another point; naming alone earns nothing. In **Classic mode**, each found neighbor reveals its stars, border, and label at the selected magnitude limit. Finding all neighbors automatically starts another star-only round after a short pause. Scores distinguish constellation identifications from neighbor placements and continue across rounds. Reveal name and Skip remaining neighbors allow practice without awarding points for skipped answers; New game resets the score. Scores last for the current page session.

Choose **Conquer mode** to claim one starting constellation and then expand through any unclaimed constellation bordering **any** existing claim. Correct placement reveals each region's stars and border. Claims and scores stay in one growing map; finding the starting constellation's neighbors does not start a new round. **View around** lets you travel to any claimed constellation to explore the full sky without forgetting claims or a pending target. All 88 constellations are reachable, including regions with no qualifying stars. Claiming all 88 ends the game and preserves the final territory for viewing. Conquer requires correct identification of the starting pattern and has no reveal/skip shortcuts. Changing modes starts a new game; the existing star-finding game's separate session export/import remains available there.

The new game defaults to two separate **inclusive magnitude 4.00** controls. **Show stars** (0.00–5.00) sets which stars are drawn. **Starting brightest** (−2.00–5.00) allows a constellation to be chosen only if its brightest catalog star has magnitude at most that threshold. For example, Show stars 4.00 and Starting brightest 2.00 keeps the fuller star picture while selecting constellations with a magnitude-2-or-brighter star. A starting constellation must also have at least one visible star. Both rules apply to Classic rounds and the Conquer seed, with no restrictions on neighboring discoveries or claims. Updating a threshold preserves scores and claims; only an unanswered pattern that stops qualifying is replaced. Settings with no eligible starting patterns are rejected without changing the session. The interface reports the number of matching starting constellations.

Use **Hint: IAU boundary** in either mode to show the unnamed starting constellation's official boundary as a dashed outline. Its name and neighboring stars stay hidden; toggling the hint does not award points or change the map view, guesses, or claims. It defaults off and preserves your choice across rounds, new games, and mode changes. Turning it off hides the hint while retaining borders earned by correct answers.

The constellation game supports drag-to-pan, wheel/button zoom, touch placement, and keyboard arrows/Enter/Escape. It accepts case differences and unaccented Latin spellings such as `Bootes` for `Boötes`, but not English translations or three-letter abbreviations. Stars and outlines keep the same map coordinates when you submit a name. Borders are precessed from B1875 to J2000, and hit-testing uses the same source regions, including RA wrap, polar constellations, and both parts of Serpens. See [CONSTELLATION-SOURCES.md](CONSTELLATION-SOURCES.md) for data credits and rebuild instructions.

Choose the Stars or Messier library, then search by name or catalog designation. Examples: `Betelgeuse`, `alpha orion`, `α Ori`, `40 Eridani`, `HIP 19849`, `M31`, `Messier 31`, or `Orion Nebula`. Search filters the picker as you type; use the arrows to browse 30 entries at a time. Searching an exact object from the other library switches the picker automatically. Each library remembers your last target.

Selecting a target or library keeps the reference chart, zoom, score, and found objects. Pan or zoom to explore, or explicitly choose a different reference chart; progress and each chart's view are retained. Changing difficulty or choosing Explore again starts a new expedition. Both stars and Messier objects use a 2° placement tolerance; place the catalog center of a Messier object.

Use the seasonal tabs for **Winter sky** (Orion), **Spring sky** (Leo), **Summer sky** (Deneb), or **Autumn sky** (Pegasus), alongside **Northern sky** (the Big Dipper). Autumn centers on the four reference stars of the Great Square: Markab, Scheat, Alpheratz, and Algenib. Spring centers on Leo, with the Sickle and the body ending at Denebola. These patterns use the existing J2000 catalog and the same angular scale as the other charts. Both are also available in the Reference chart selector, and support the full star and Messier libraries. Season names follow Northern Hemisphere usage. The atlas remains a static chart, independent of your location or time.

Charts use a consistent stereographic angular scale. The 10° ruler gives the local scale; star markers and labels retain their screen size when zooming. Explorer guide lines connect reference stars and stars you have found, with an equatorial grid every 15°. Hidden targets are never drawn. Expert mode disables guides and hints.

Use **Names on/off** below the map to hide or restore all map labels (including Messier names). This preference is saved on your device. **Edit lines** lets you click two found or reference stars to add a connection; repeat the same pair to remove it, including an automatic constellation line. The first endpoint is highlighted. Click it again or press Escape to cancel it; another Escape or **Done editing** resumes guessing. Arrow keys and Enter also select endpoints. Editing does not change your score or count as a guess. Selecting a new target leaves editing mode.

Custom connections stay visible when automatic guides are off, including in Expert mode, and survive panning, zooming, target selection, and reference chart changes. Starting a new expedition clears connections and restores automatic lines. Hidden targets and Messier objects cannot be endpoints.

Use **Export session** above the map to download a dated `starpath-session-….json` file. **Import session** opens that file and replaces the current expedition, restoring your score, discovered stars and Messier objects, selected target and library, difficulty, hints and wrong guesses, chart and saved views, name/guide visibility, custom connections (including removed automatic lines), and picker state. You can resume on another device with the same app version. Session files contain data only and stay on your device; the app does not upload them. Invalid files, unavailable catalog objects or charts, unsupported session versions, and files over 5 MB are rejected without changing your progress. Importing retains the higher of the device's personal best and the saved score. Progress is saved when you export; refreshing without exporting still starts a new expedition.

The bundled `bright-stars.js` contains all **1,637 non-Solar entries with apparent visual magnitude ≤ 5.00** from [HYG v4.0](https://github.com/astronexus/HYG-Database/blob/main/hyg/CURRENT/hygdata_v40.csv.gz), including separate binary components. Positions use J2000 coordinates; variable-star magnitudes are catalog values. Stars can be searched by common names, Bayer and Flamsteed designations (constellation abbreviations, nominative and genitive names), and HIP/HD/HR identifiers. Duplicate names receive a HYG ID suffix. The catalog is adapted from HYG under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); see `HYG-LICENSE.txt`.

`messier-objects.js` contains **M1–M110**, regardless of magnitude, and shows found objects as small diamonds. Coordinates and metadata for 109 entries come from the [NASA HEASARC Messier catalog](https://heasarc.gsfc.nasa.gov/W3Browse/general-catalog/messier.html), which omits the historically disputed M102. We include M102 as NGC 5866 (Spindle Galaxy), using J2000 coordinates from [OpenNGC](https://github.com/mattiaverga/OpenNGC) by Mattia Verga under CC BY-SA 4.0; see `OPENNGC-LICENSE.txt`. This identification is also used in [NASA's Hubble Messier catalog](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-102/).

To rebuild the bundled data, download the [HYG CSV](https://raw.githubusercontent.com/astronexus/HYG-Database/main/hyg/CURRENT/hygdata_v40.csv.gz), [HEASARC table](https://heasarc.gsfc.nasa.gov/FTP/heasarc/dbase/tdat_files/heasarc_messier.tdat.gz), and [OpenNGC CSV](https://raw.githubusercontent.com/mattiaverga/OpenNGC/master/database_files/NGC.csv), then run `python tools/build_catalogs.py /path/to/hyg.csv.gz /path/to/messier.tdat.gz /path/to/NGC.csv`. The script filters HYG by the inclusive magnitude cutoff, converts HEASARC right ascension from degrees to hours, and checks the complete Messier sequence and unique catalog names.
